勾股定理：比较同一个大正方形的面积

四个全等直角三角形围成一个边长为 c 的正方形。

  1. 大正方形的面积是 (a + b)2。
  2. 它也等于四个直角三角形的面积，加上中心正方形的面积。
(a + b)2 = 4 · ab2 + c2
两种面积算法相等
a2 + 2ab + b2 = 2ab + c2
展开括号
a2 + b2 = c2
两边同时减去 2ab
a2 + b2 = c2

正弦定理：同一条高的两种表示

在三角形 ABC 中，边 a, b, c 分别与角 A, B, C 相对。

在左、右两个直角三角形中，分别使用正弦的定义：

sin A = hb　⇒　h = b sin A
在 △ACD 中
sin B = ha　⇒　h = a sin B
在 △BCD 中

因为两式表示的是同一条高，所以

b sin A = a sin B　⇒　sin Aa = sin Bb

再从另一个顶点作高，同理可得 sin Bb = sin Cc。

sin Aa = sin Bb = sin Cc
常见写法：取倒数即可得到 asin A = bsin B = csin C。
3

余弦定理：把一边分解成投影

向边 CB 作高，把斜边 b 在底边方向的投影写成 b cos C。

方法一：垂线与投影

  1. 在直角三角形 △ACD 中，h2 = b2 − x2。
  2. 在直角三角形 △ADB 中，c2 = h2 + (a − x)2。
c2 = (b2 − x2) + (a − x)2
代入 h2
c2 = a2 + b2 − 2ax
展开并消去 ±x2
c2 = a2 + b2 − 2a(b cos C)
代入 x = b cos C
c2 = a2 + b2 − 2ab cos C

方法二：坐标法

这是最直接的证明。把角 C 放到坐标原点，并把边 CA 放在 x 轴正方向上。

边 CB 在水平和竖直方向的分量分别为 a cos C 与 a sin C，所以

B = (a cos C, a sin C)

因为 AB = c，由两点距离公式：

c2 = (b − a cos C)2 + (0 − a sin C)2
计算 AB2
c2 = b2 − 2ab cos C + a2 cos2 C + a2 sin2 C
展开平方
c2 = b2 − 2ab cos C + a2(cos2 C + sin2 C)
合并后两项
c2 = a2 + b2 − 2ab cos C
sin2 C + cos2 C = 1
c2 = a2 + b2 − 2ab cos C
为什么会出现 −2ab cos C？ 边 a 在边 b 方向上的投影是 a cos C，因此水平方向的距离是 b − a cos C。把它平方，中间项自然就是 −2ab cos C。
与勾股定理的关系：当 C = 90° 时，cos 90° = 0，余弦定理立刻化为 c2 = a2 + b2。所以勾股定理是余弦定理的特殊情况。
4

两角和公式：先证余弦差角，再推出和角

核心想法是旋转不改变距离。单位圆上两点的弦长，只取决于它们的夹角。

弦长的两种坐标计算

P = (cos A, sin A)，
Q = (cos B, sin B)。

R = (cos(A − B), sin(A − B))，
S = (1, 0)。

旋转是刚体变换，所以对应弦长相等：PQ2 = RS2。
PQ2 = (cos A − cos B)2 + (sin A − sin B)2
两点距离公式
PQ2 = 2 − 2(cos A cos B + sin A sin B)
展开，并用 sin2x + cos2x = 1
RS2 = [cos(A − B) − 1]2 + sin2(A − B)
两点距离公式
RS2 = 2 − 2cos(A − B)
平方和为 1

令两式相等，约去相同项并除以 −2：

cos(A − B) = cos A cos B + sin A sin B

由差角公式得到余弦和角公式

在差角公式中把 B 换成 −B，并使用 cos(−B) = cos B、sin(−B) = −sin B：

cos(A + B) = cos A cos B − sin A sin B

由余弦差角公式得到正弦和角公式

利用余函数关系 sin x = cos(π2 − x)：

sin(A + B) = cos[π2 − (A + B)]
余函数关系
= cos[(π2 − A) − B]
整理括号
= cos(π2 − A) cos B + sin(π2 − A) sin B
应用余弦差角公式
= sin A cos B + cos A sin B
再次使用余函数关系
正弦和角公式 sin(A + B) = sin A cos B + cos A sin B
余弦和角公式 cos(A + B) = cos A cos B − sin A sin B
