1

集合的概念、子集、交集、并集与补集

把研究对象放进“容器”，再研究容器之间的关系。

1.1 集合与元素

把一些确定的、互不相同的对象作为一个整体，这个整体叫作集合；其中每个对象叫作集合的元素。

确定性

对任意对象，都能判断它是否属于该集合。“比较高的同学”标准不清，一般不能直接组成集合。

互异性与无序性

同一元素只写一次；元素次序不影响集合，所以 {1,2}={2,1}。

若 a 是集合 A 的元素，写作 a∈A；否则写作 a∉A。常用表示法：

  • 列举法：A={1,2,3}；适合元素较少的集合。
  • 描述法：A={x∈Z | 1≤x≤3}；竖线“|”读作“满足”。
  • 区间法：{x∈R | 1≤x<3}=[1,3)。方括号包含端点，圆括号不包含端点。

1.2 子集、真子集与相等

A⊆B ⇔ 对任意 x，x∈A 都能推出 x∈B。
A=B ⇔ A⊆B 且 B⊆A。
A⊊B ⇔ A⊆B 且 A≠B。

空集 ∅ 不含任何元素，但它是任意集合的子集。若有限集合 A 有 n 个元素，则：

A 的子集个数为 2ⁿ；真子集个数为 2ⁿ−1；非空真子集个数为 2ⁿ−2（n≥1）。
为什么是 2ⁿ？ 构造一个子集时，A 的每个元素都有“选入”或“不选入”两种独立选择。n 个元素共有 2×2×…×2=2ⁿ 种选择。

1.3 交、并、补

运算定义关键词
A∩B{x | x∈A 且 x∈B}同时、公共部分
A∪B{x | x∈A 或 x∈B}至少属于一个
∁UA{x∈U | x∉A}全集 U 中除去 A
A\B{x | x∈A 且 x∉B}属于 A 但不属于 B
“或”可以兼容：x∈A 或 x∈B，包括 x 同时属于 A、B 的情况。因此并集不是把公共元素删掉。

1.4 重要运算律与证明方法

交换律：A∩B=B∩A，A∪B=B∪A
分配律：A∩(B∪C)=(A∩B)∪(A∩C)
德摩根律：∁U(A∪B)=∁UA∩∁UB
证明德摩根律（任取元素法）
任取 x∈U：
x∈∁U(A∪B) ⇔ x∉A∪B
⇔ x∉A 且 x∉B
⇔ x∈∁UA 且 x∈∁UB
⇔ x∈∁UA∩∁UB。
两边包含完全相同的元素，所以两集合相等。
配套例题 1｜集合表示与子集计数

题目：A={x∈Z | x²−5x+6=0}。写出 A，并求 A 的所有子集。

思路先解方程确定元素，再对每个元素作“取或不取”的选择。

  1. x²−5x+6=(x−2)(x−3)=0，所以 x=2 或 x=3。
  2. 因此 A={2,3}，有 2 个元素，子集共有 2²=4 个。
  3. 按元素个数列举：0 个元素为 ∅；1 个元素为 {2}、{3}；2 个元素为 {2,3}。

结论：A={2,3}；所有子集为 ∅、{2}、{3}、{2,3}。

配套例题 2｜区间的交、并、补

题目：全集 U=R，A=[−1,3)，B=(1,5]。求 A∩B、A∪B、∁UA。

思路先在数轴上判断重叠部分与总覆盖范围，最后特别检查端点是否包含。

  1. 同时属于 A、B，需要 x>1 且 x<3，所以 A∩B=(1,3)。
  2. 两个区间相连且有重叠，总覆盖从 −1 到 5。−1 属于 A，5 属于 B，所以 A∪B=[−1,5]。
  3. 在 R 中除去 [−1,3)：−1 被 A 包含，补集不含 −1；3 不属于 A，补集包含 3。

结论：A∩B=(1,3)，A∪B=[−1,5]，∁RA=(−∞,−1)∪[3,+∞)。

配套例题 3｜由集合包含关系求参数

题目：A={1,2}，B={1,a,a²}。若 A⊆B，求实数 a。

思路A 的每个元素都必须出现在 B 中。1 已在 B 中，只需确保 2∈B。

  1. 2∈B 意味着 2=a 或 2=a²。
  2. 由 a=2 得一个解；由 a²=2 得 a=±√2。
  3. 逐一检验：a=2 时 B={1,2,4}；a=±√2 时 a²=2，B 均包含 1 和 2。

结论：a∈{2,√2,−√2}。注意集合元素重复不会影响集合。

命题与逻辑

把自然语言改写成可以判断真假的数学语言。

2.1 命题与逻辑联结词

能够判断真假的陈述句叫作命题。命题不是一定为真，而是必须具有确定的真假性。

符号读法何时为真
¬p非 pp 为假
p∧qp 且 qp、q 都真
p∨qp 或 qp、q 至少一个真
p⇒q若 p，则 q只有“p 真而 q 假”时为假
p⇔qp 当且仅当 qp、q 同真或同假

2.2 充分条件与必要条件

若 p⇒q，则 p 是 q 的充分条件，q 是 p 的必要条件。

判断时建议画箭头：从条件 p 出发，能否必然推出结论 q？

  • p⇒q，但 q⇏p：p 是 q 的充分不必要条件。
  • q⇒p，但 p⇏q：p 是 q 的必要不充分条件。
  • p⇔q：p 是 q 的充分必要条件。
  • 两个方向都不成立：p 是 q 的既不充分也不必要条件。

2.3 原命题、逆命题、否命题、逆否命题

名称形式与原命题的真假关系
原命题若 p，则 q—
逆命题若 q，则 p不一定相同
否命题若 ¬p，则 ¬q不一定相同
逆否命题若 ¬q，则 ¬p与原命题等价
为什么原命题与逆否命题等价？ 原命题 p⇒q 只有一种失败情形：p 真、q 假。逆否命题 ¬q⇒¬p 的失败情形是 ¬q 真、¬p 假，也就是 q 假、p 真。二者失败情形完全相同，因此真假永远一致。

2.4 全称量词、存在量词及否定

全称命题：∀x∈M，p(x)；否定为 ∃x∈M，使 ¬p(x)。
存在命题：∃x∈M，使 p(x)；否定为 ∀x∈M，¬p(x)。
否定不能只改结论：“所有”要变成“至少存在一个”，“存在”要变成“所有都不”。例如“所有实数平方均为正”的否定是“存在一个实数，其平方不为正”。
配套例题 4｜充分条件与必要条件

题目：对实数 x，p：x>2；q：x²>4。判断 p 是 q 的什么条件。

思路分别检验 p⇒q 与 q⇒p。

  1. 若 x>2，则 x²>4，所以 p⇒q 成立。
  2. 若 x²>4，则 x>2 或 x<−2；例如 x=−3 满足 q，却不满足 p，所以 q⇒p 不成立。

结论：p 是 q 的充分不必要条件。

配套例题 5｜写出量词命题的否定

题目：否定命题“∀x∈R，x²−2x+2>0”。

思路全称量词变存在量词，“>0”的否定是“≤0”。

  1. 把“对所有实数 x”改为“存在实数 x”。
  2. 把性质 x²−2x+2>0 否定为 x²−2x+2≤0。
  3. 可顺便判断原命题：x²−2x+2=(x−1)²+1>0，因此原命题为真，其否定为假。

否定：∃x∈R，使 x²−2x+2≤0。

配套例题 6｜用逆否命题证明

题目：设 n∈Z，证明：若 n² 为偶数，则 n 为偶数。

思路直接从 n² 偶数分析较绕，证明等价的逆否命题：“若 n 不是偶数，则 n² 不是偶数”。

  1. n 不是偶数，即 n 为奇数，可写成 n=2k+1（k∈Z）。
  2. n²=(2k+1)²=4k²+4k+1=2(2k²+2k)+1。
  3. 2k²+2k 是整数，所以 n² 形如 2m+1，是奇数。
  4. 逆否命题成立，因此原命题成立。

结论：n² 为偶数必能推出 n 为偶数。

数域的概念与性质

不仅要知道“有哪些数”，还要知道运算后是否仍留在这个集合中。

3.1 常用数集的包含关系

N ⊆ Z ⊆ Q ⊆ R，且无理数集为 R\Q。
数集含义例子
N自然数集（教材可能约定是否含 0，做题先看说明）0,1,2,…
Z整数集−2,0,5
Q有理数集，可写为 p/q，p,q∈Z，q≠0−3, 2/5, 0.125
R实数集：有理数与无理数的全体√2, π, −7/3

3.2 什么是数域

在中学常见表述中，若非空数集 K 对加、减、乘、除（除数不为 0）都封闭，就称 K 为一个数域。所谓“封闭”，是指取 K 中任意两个数做相应运算，结果仍在 K 中。

任意 a,b∈K：a±b∈K，ab∈K；当 b≠0 时，a/b∈K。
集合加减乘除（非零除数）是否数域
N封闭不封闭封闭不封闭否
Z封闭封闭封闭不封闭否
Q封闭封闭封闭封闭是
R封闭封闭封闭封闭是
最小数域：任何数域都必须含 0 和 1，也必须含所有整数及其非零商，因此必含 Q。所以 Q 是包含于 R 的最小数域。

3.3 实数的有序性与稠密性

  • 有序性：任意实数 a、b，a<b、a=b、a>b 三者恰有一个成立。
  • 稠密性：任意两个不同实数之间，都有无穷多个有理数，也有无穷多个无理数。
  • 绝对值：|x| 表示 x 到原点的距离；|x−a| 表示 x 与 a 的距离。
配套例题 7｜判断运算封闭性

题目：K={a+b√2 | a,b∈Q}。证明 K 对加、减、乘、除（除数非零）封闭。

思路任取两个一般元素，逐项运算，再把结果整理成“有理数+有理数×√2”的形式。

  1. 任取 x=a+b√2，y=c+d√2，其中 a,b,c,d∈Q。
  2. x±y=(a±c)+(b±d)√2，两个系数仍为有理数，所以 x±y∈K。
  3. xy=(ac+2bd)+(ad+bc)√2，各系数仍为有理数，所以 xy∈K。
  4. 当 y≠0 时，有
    x/y = [(a+b√2)(c−d√2)]/(c²−2d²) = [(ac−2bd)+(bc−ad)√2]/(c²−2d²)。
    若 c²−2d²=0 且 d≠0，会推出 (c/d)²=2，使有理数 c/d 等于 ±√2，矛盾；若 d=0，则 y≠0 保证 c≠0。因此分母不为 0，两个新系数仍为有理数。

结论：K 对四则运算封闭，因此 K 是一个数域。

配套例题 8｜证明 √2 是无理数

题目：用反证法证明 √2∉Q。

思路假设 √2 可写成最简分数 p/q，然后证明 p、q 都是偶数，与“最简”矛盾。

  1. 假设 √2=p/q，其中 p,q∈Z，q≠0，且 p、q 互质。
  2. 平方得 2=p²/q²，即 p²=2q²，所以 p² 是偶数。
  3. 由“整数平方为偶数，则整数为偶数”，得 p=2k。
  4. 代回：(2k)²=2q²，化简得 q²=2k²，所以 q 也是偶数。
  5. p、q 同为偶数，至少有公因数 2，与二者互质矛盾。

结论：原假设错误，因此 √2 是无理数。

配套例题 9｜最小数域思想

题目：设 K 是数域，且 √3∈K。证明对任意 a,b∈Q，都有 a+b√3∈K。

思路数域一定含 Q，再利用对乘法、加法封闭。

  1. 任何数域都含所有有理数，所以 a∈K，b∈K。
  2. 已知 √3∈K，且 K 对乘法封闭，所以 b√3∈K。
  3. K 对加法封闭，因此 a+b√3∈K。

结论：含 √3 的数域必然包含集合 {a+b√3 | a,b∈Q}。

新高考“新定义”问题

考点不是背诵陌生符号，而是现场把定义翻译成已学知识。

四步解题法

  1. 圈出对象：新定义作用于数、集合、命题还是函数？变量的范围是什么？
  2. 翻译规则：把新符号完整改写成“∩、∪、补集、方程、不等式”等熟悉语言。
  3. 按规则计算：不要凭符号外观猜运算性质；每一步回到定义。
  4. 检查边界：空集、端点、重复元素、除数为 0、量词范围常是设陷处。
配套例题 10｜新集合运算：对称差

题目：定义 A△B=(A\B)∪(B\A)，即只属于 A、B 中一个的元素组成的集合。若 A={1,2,3,4}，B={3,4,5}，求 A△B，并证明 A△B=(A∪B)\(A∩B)。

思路先按定义计算；证明集合恒等式时任取元素，比较两边的归属条件。

  1. A\B={1,2}，B\A={5}，所以 A△B={1,2,5}。
  2. 任取 x。x∈A△B，意味着“x∈A 且 x∉B”或“x∈B 且 x∉A”。
  3. 这等价于 x 至少属于 A、B 中一个，但不能同时属于二者。
  4. 也就是 x∈A∪B 且 x∉A∩B，即 x∈(A∪B)\(A∩B)。

结论：A△B={1,2,5}，且 A△B=(A∪B)\(A∩B)。

配套例题 11｜新关系与充分必要条件

题目：对实数集的两个非空子集 A、B，定义 A≼B 表示“任意 a∈A、b∈B，都有 a≤b”。设 A=[−1,m]，B=[2,5]。求 A≼B 成立的充要条件。

思路“任意 a 都不超过任意 b”只需比较 A 的最大值与 B 的最小值。

  1. A 非空要求 m≥−1；此时 A 的最大值为 m。
  2. B 的最小值为 2。
  3. 若 A≼B，则特别取 a=m、b=2，必须有 m≤2，这是必要条件。
  4. 反过来，若 m≤2，则任意 a∈A 有 a≤m≤2；任意 b∈B 有 b≥2，所以 a≤b。这说明条件也充分。

结论：在 A 非空的前提下，A≼B ⇔ −1≤m≤2。

配套例题 12｜新定义“稳定集合”

题目：若非空数集 S 满足：对任意 x,y∈S，都有 x+y∈S，则称 S 为“加法稳定集”。判断下列集合是否稳定，并说明理由：①Z；②正奇数集；③{0,2,4,6,…}。

思路要证明“是”，需验证任意元素；要证明“不是”，只需找到一个反例。

  1. ①任意两个整数之和仍为整数，因此 Z 是加法稳定集。
  2. ②取 1 和 3，二者均为正奇数，但 1+3=4 不是奇数；存在一个反例即可否定，所以正奇数集不是。
  3. ③任取两个非负偶数 x=2m、y=2n（m,n∈N），则 x+y=2(m+n)，仍为非负偶数，所以该集合是。

结论：①是；②不是；③是。全称性质的证明与否定方式不同。

结课自测

先独立完成，再展开答案。

  1. 已知 U={1,2,3,4,5,6}，A={1,2,4}，B={2,3,4,5}，求 (∁UA)∩B。
  2. 集合 A 有 5 个元素，它有多少个非空真子集？
  3. 判断：“x=1”是“x²=1”的什么条件（x∈R）？
  4. 写出“∃x∈R，使 x²+x+1=0”的否定，并判断原命题真假。
  5. 说明 Z 为什么不是数域。
  6. 定义 A⊙B=(A∪B)\(A∩B)。若 A={a,b,c}，B={b,c,d}，求 A⊙B。
  7. 设 A=(−∞,a]，B=[3,+∞)。按例题 11 的定义，求 A≼B 的充要条件。
展开自测答案与简要步骤
  1. ∁UA={3,5,6}，与 B 取交集得 {3,5}。
  2. 2⁵−2=30。
  3. x=1⇒x²=1；反向不成立（x=−1 是反例），所以是充分不必要条件。
  4. 否定：∀x∈R，x²+x+1≠0。因为判别式 Δ=1−4=−3<0，原命题为假，否定为真。
  5. 例如 1,2∈Z，但 1÷2=1/2∉Z，故 Z 对除法不封闭。
  6. A⊙B={a,d}。
  7. A 的最大值是 a，B 的最小值是 3，因此 A≼B⇔a≤3。
